# Gitee Platform Config — Read Only

> ⚠️ **Do not edit, rename or delete any configuration file in this directory.**
> Documentation only — read it once, then leave the config files alone.

`.gitee/` holds the Gitee issue template configuration (4 files):

| File | Purpose |
| --- | --- |
| `ISSUE_TEMPLATE/config.yml` | Disables blank issues, links to the Chinese docs |
| `ISSUE_TEMPLATE/question.yml` | Usage question template |
| `ISSUE_TEMPLATE/bug.yml` | Bug report template |
| `ISSUE_TEMPLATE/enhancement.yml` | Feature request template |

**Leave these files alone.** If a change is truly needed, check the impact first.

# Gitee 平台配置 — 只读须知

> ⚠️ **请勿修改、重命名或删除本目录中的任何配置文件。**
> 本文件只是说明文档，读一遍即可。

`.gitee/` 存放 Gitee 平台的 Issue 模板配置，共 4 个文件：

| 文件 | 用途 |
| --- | --- |
| `ISSUE_TEMPLATE/config.yml` | 关闭空白 Issue，提供中文文档入口 |
| `ISSUE_TEMPLATE/question.yml` | 使用疑问模板 |
| `ISSUE_TEMPLATE/bug.yml` | 问题反馈模板 |
| `ISSUE_TEMPLATE/enhancement.yml` | 功能建议模板 |

**默认不要动。** 如确需调整，先确认影响范围再改。
